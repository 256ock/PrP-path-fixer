PrP Path Fixer

Premiere Pro のプロジェクト (.prproj) を Mac ⇔ Windows で受け渡したときに、濁点・半濁点を含む素材パスがリンク切れになる問題を修復します。

1. このプロジェクトを開く OS

2. .prproj をドロップ

ここに .prproj をドラッグ＆ドロップ
またはクリックして選択（複数可）

ファイルはこのブラウザ内だけで処理され、どこにも送信されません。修復したファイルは 元の名前_win.prproj / 元の名前_mac.prproj として保存されます（元ファイルは変更されません）。
