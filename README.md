# PrP Path Fixer

**Mac と Windows で Premiere Pro のプロジェクトを受け渡すと、ファイル名に濁点・半濁点がある素材だけ「メディアオフライン」になる。** その問題を直すツールです。

ブラウザで開いて `.prproj` をドロップするだけ。インストール不要で、ファイルは外部に送信されません。

## こんな症状に

- Mac で作ったプロジェクトを Windows で開くと、「ガイド.mov」「パーティー.wav」のような **濁点・半濁点を含む名前の素材だけ** リンクが切れる
- 「メディアをリンク」で指定しても、1 つずつしか直らない／見つからない
- Windows → Mac の受け渡しでも同じことが起きる

## 使い方

### 👉 https://256ock.github.io/PrP-path-fixer/

1. 上のページをブラウザで開く（Chrome / Edge / Safari / Firefox）
2. **このプロジェクトを開く OS** を選ぶ（いま使っているパソコンの OS が最初から選ばれています）
   - Mac から受け取ったプロジェクトを Windows で開く →「Windows で開く」
   - Windows から受け取ったプロジェクトを Mac で開く →「Mac で開く」
3. `.prproj` をドラッグ＆ドロップ（複数可）
4. 修復済みの `元の名前_win.prproj` / `元の名前_mac.prproj` がダウンロードフォルダに保存される
5. それを Premiere Pro で開く

元のファイルは変更しません。ページで開いていても、ファイルはブラウザの中だけで処理され、サーバーには送信されません。

**オフラインで使いたい場合**は、[`index.html`](index.html) を開いて右上のダウンロードボタン（Download raw file）で保存し、ダブルクリックで開いてください。

## なぜ起きるのか

「ガ」という文字は、コンピューターの中で 2 通りの表し方ができます。

| 表し方 | 中身 | 主に使う OS |
|------|------|-------------|
| 合成形（NFC） | `ガ` の 1 文字 | Windows |
| 分解形（NFD） | `カ` ＋ `゛` の 2 文字 | macOS |

画面上は同じ「ガ」でもデータとしては別物です。Mac で作ったプロジェクトには分解形のパスが記録されるため、Windows 上の合成形のファイル名と一致せず、リンクが切れます。英数字や、濁点・半濁点のないかな・漢字では起きないため、「一部の素材だけ切れる」という症状になります。

このツールは `.prproj`（中身は gzip 圧縮された XML）を展開し、**素材のパスの部分だけ** を開く側の OS の表し方に変換して保存し直します。

## 変換元の OS 特有の場所の案内

素材が変換元の OS に特有の場所にある場合、結果の欄に ⚠ で場所ごとの件数と対処法を表示します。濁点・半濁点の修正が不要なプロジェクトでも表示されます。

| 変換元 | 案内する場所の例 |
|------|------|
| Mac | デスクトップ・書類・ムービーなどのユーザーフォルダ、iCloud Drive、Dropbox などのクラウドストレージ、外付けドライブ・NAS（`/Volumes`）、起動ディスク |
| Windows | デスクトップ・ドキュメント・ビデオなどのユーザーフォルダ、OneDrive などのクラウドストレージ、C ドライブ、ドライブ文字（`D:` など）、ネットワーク共有（`\\サーバー`） |

これらの場所は、受け取った側のパソコンでは同じパスにならないため、濁点を直しても「メディアをリンク」での指定が必要になります。Premiere Pro のキャッシュなど、素材以外のファイルは対象外です。

## うまくいかないとき

- **ドライブ名やフォルダ構成が違う場合**（例: Mac の `/Volumes/素材/` → Windows の `D:\素材\`）は、修復後も Premiere Pro の「メディアをリンク」で場所を指定してください。濁点の問題は解消されているので、フォルダを 1 つ指定すれば残りは自動で見つかるようになります。
- **それでもつながらない場合**は、逆の方向（「Mac で開く」⇔「Windows で開く」）で試してください。NAS・USB メモリ・クラウドストレージなど、コピー方法によっては素材ファイルの名前自体が分解形のまま Windows に渡っていることがあります。
- クリップ名やシーケンス名の濁点も揃えたい場合は、「パス以外（クリップ名・シーケンス名など）も変換する」にチェックを入れてください（リンクの修復には不要です）。

## 注意

- 念のため、元のプロジェクトのバックアップを取ってから使ってください。
- 「﨑」のような一部の異体字（CJK 互換漢字）は、変換すると別の字（「崎」）に置き換わってしまうため、変換しません（macOS と同じ扱い）。
